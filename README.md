# Adrien Does Post Rock

Personal showcase for TrackRelay, PitchPilot, Kemper Display and KemperControlDAW.

Website: https://adriendoespostrock.github.io

## Publishing

In repository Settings → Pages, choose **Deploy from a branch**, **main**, and **/ (root)**.

This is a static website. No build command or dependencies are required.

## Editing

- `index.html`: copy, application sections and download links.
- `styles.css`: layout, typography and responsive styling.
- `assets/`: application screenshots, icon and favicon.

Download links point to the latest GitHub releases. PitchPilot is listed with its macOS release and setup requirements. The Bluetooth availability note must be reviewed when the updated Mac application and iPhone companion are released.

Screenshots are supplied by the application author. Design inspired by the presentation approach of CamOrder Studio; code and copy written for this site.
